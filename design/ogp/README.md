# OGP画像の元データ

`public/ogp.png`（SNSでシェアしたときに出る画像、1200×630）を作るためのファイルです。
このフォルダはサイトの公開には使われません（`design/` はビルドの対象外です）。

| ファイル | 中身 |
|---|---|
| `ogp.html` | OGP画像のデザイン。Chromeで開くと画像と同じ見た目になる |
| `keypale.png` | KeyPale のカード画像（BOOTHの商品画像のコピー） |

ほかのカード画像は `public/products/` と `public/tecopi_ogp.png` をそのまま読み込んでいます。

## 作り直したいとき

### いちばん簡単な方法
Claude に「design/ogp の OGP 画像を作り直して」と頼み、変えたいところ（カードの入れ替え・文言など）を伝える。

### 自分で画像にする方法（Chrome）
1. `ogp.html` を Chrome で開く
2. F12 で開発者ツールを開き、左上の「デバイスのツールバー」ボタン（スマホとタブレットの絵）を押す
3. 画面上部のサイズ欄を `1200` × `630`、倍率を 100% にする
4. 開発者ツール右上の「︙」→「コマンドを実行」（Ctrl+Shift+P）で `screenshot` と入力し、「スクリーンショットをキャプチャ」を選ぶ
5. 保存された画像を `public/ogp.png` に上書きする

※ 文字のフォント（Zen Maru Gothic）はインターネットから読み込むので、ネットにつながった状態で開いてください。
